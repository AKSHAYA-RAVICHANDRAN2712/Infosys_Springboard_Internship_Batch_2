# MediSphere Healthcare Management — Clinical Operations

## Milestone 4: Careplan & Intervention

This Vite + React demo now includes a complete clinical operations workspace rather than a predictions-only screen.

### Included modules
- Dashboard: KPIs, today's schedule, clinical performance, prioritized patients and alerts.
- Patients: searchable patient registry with risk, readings and care provider information.
- Tasks: clinical task board with To Do, In Progress and Completed workflows.
- Predictions: AI-assisted risk score, model confidence, risk contributors, prediction outlook, personalized careplan, outcomes, provider collaboration and guideline compliance.
- Alerts: prioritized clinical alerts with review actions.
- Careplans: active careplan metrics, adherence and plan registry.
- Reports: operational reports, monthly snapshot and outcome analytics.

### Run locally
```bash
npm install
npm run dev
```
